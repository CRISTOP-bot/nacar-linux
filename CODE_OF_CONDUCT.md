# Code of conduct

Participation in this project is conditional on treating people with respect. Harassment, discrimination, threats, personal attacks, doxxing, and sustained disruptive behavior are not acceptable.

Be constructive, assume good faith while discussing technical disagreements, and focus criticism on ideas and code rather than people. Maintainers may edit or remove contributions that violate this policy and may restrict participation when necessary to protect the community.

Report a conduct concern privately to the repository maintainers through a contact method listed in the GitHub repository. Do not publish sensitive personal information in an issue.
